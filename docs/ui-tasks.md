## Decisions (answered 12 November 2026)

1. **Appearance setting storage (U3):** stored on each device, not synced. No schema change; phone and desktop can differ. Ask before adding a dependency to store it on the phone.
2. **Copy last note and Clear (U6, U7):** removed from both apps.
3. **Quick chips:** dropped. Remove them from the design brief (U0) and close the Discovered item.
4. **Desktop preview screen (U11):** the separate Invoice preview screen goes away. Download PDF and Mark as sent move to a small menu beside Send invoice; Download PDF is also on the invoice detail (U10).
5. **Visit picker on the phone (U8):** the draft (and its proposed number) is created only on "Continue"; Cancel leaves nothing behind.
6. **Desktop Home:** takes the phone board's new tags, to-do count cards and recent rows; its layout otherwise stays as it is.
